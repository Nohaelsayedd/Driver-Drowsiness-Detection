# Driver-Drowsiness-Detection
Clone the repo: git clone https://github.com/Nohaelsayedd/Driver-Drowsiness-Detection.git

Go into the folder: cd Driver-Drowsiness-Detection

Create a virtual environment: python -m venv venv

Activate it — Windows: venv\Scripts\activate / Mac: source venv/bin/activate

Install everything: pip install -r requirements.txt
